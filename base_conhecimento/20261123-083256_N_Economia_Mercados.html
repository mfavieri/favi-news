Boletim Focus eleva projeções para inflação e dólar e prevê Selic a 13% em 2027

📍 Fonte: InfoMoney Mercados  |  🕒 Data do Fato: 23/11/2026 às 08h32

As projeções do mercado financeiro para a inflação brasileira subiram para 2026 e 2027, segundo o Relatório Focus divulgado pelo Banco Central nesta segunda-feira (23). A mediana para o IPCA deste ano passou de 5,11% para 5,15%, enquanto a estimativa para 2027 avançou de 5,00% para 5,12%.

A estimativa para o IGP-M de 2026 avançou de 6,22% para 6,33%. Para 2027, passou de 4,35% para 4,52%. Já a projeção para o IPCA de preços administrados caiu de 4,46% para 4,40% neste ano, mas subiu de 4,70% para 4,87% em 2027.

PIB As projeções para o crescimento da economia foram revisadas para baixo nos próximos anos. A estimativa para o Produto Interno Bruto (PIB) de 2026 caiu de 1,72% para 1,70%. Para 2027, recuou de 1,02% para 1,00%, enquanto a previsão para 2028 passou de 1,80% para 1,71%. Para 2029, permaneceu em 2,00%.

No câmbio, a expectativa para o dólar subiu de R$ 5,40 para R$ 5,55 em 2026. Para 2027, a projeção avançou de R$ 5,45 para R$ 5,50. As estimativas para 2028 e 2029 também subiram, de R$ 5,48 para R$ 5,50 e de R$ 5,50 para R$ 5,55, respectivamente.

A mediana das projeções para a taxa Selic ao fim de 2026 permaneceu em 13,75% ao ano. Para 2027, a estimativa subiu de 12,75% para 13,00%. As previsões para 2028 e 2029 ficaram estáveis em 11,00% e 10,50%, respectivamente.
